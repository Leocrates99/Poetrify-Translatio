🏗 Architettura modulare

Questo è il nuovo entry point della single-page app Poetrify. La struttura organizza il codice in moduli ES indipendenti, per ridurre il monolite HTML del translator e abilitare l'iterazione separata fra translator e dizionario su un motore condiviso.

Struttura cartelle:

poetrify/
├─ app.html                  ← questo file (loader)
├─ translator.html           ← translator attivo (sviluppo qui)
├─ dictionary.html           ← scheda dizionario (sviluppo qui)
├─ modules/
│  ├─ engine/                ← motore condiviso
│  │  ├─ taxonomies.js
│  │  ├─ conjunctions.js     LAT GR
│  │  ├─ prepositions.js     GR
│  │  ├─ cross-rules.js
│  │  ├─ conversion-table.js
│  │  ├─ text-utils.js
│  │  └─ index.js            ← facade
│  ├─ translator/            ← Fase 2 in corso
│  │  ├─ token-classifiers.js
│  │  ├─ options-renderer.js
│  │  ├─ summaries.js
│  │  └─ index.js            ← facade
│  ├─ dictionary/            (future)
│  └─ ui/                    (future)
└─ data/                     (future)
   ├─ greek-dict.json
   └─ latin-dict.json

📘 Roadmap della migrazione

Fase 1 · estrazione dati (✅ completata): le costanti del motore — preset congiunzioni, preset preposizioni, tabelle di conversione, regole cross-layer, tassonomie linguistiche — sono ora moduli ES indipendenti.

Fase 2 · UI translator (🛠 in corso): estrazione progressiva dei renderer in modules/translator/. Primo batch consegnato: token-classifiers.js · options-renderer.js · summaries.js. Il translator inline carica i moduli in modalità shadow (export modulari + smoke-test di parità rispetto alle definizioni inline). Prossimi batch: tokenizer/render-token-chip, action-bars, wizard, lemma engine.

Fase 3 · UI dizionario (pending): completamento del dizionario standalone con la card library, paradigm modal, filtri profilo.

Fase 4 · shared state (pending): introduzione di un piccolo store reattivo condiviso fra translator e dizionario; il bridge URL-query string si trasforma in event bus.

Fase 5 · data files JSON (pending): migrazione del corpus lessicale (Greek/Latin dict) da JS inline a file JSON serviti su richiesta.
